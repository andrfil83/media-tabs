# Media Tabs

Пауза и воспроизведение видео/аудио на вкладке.

## Два способа управления

### 1. Popup — список вкладок с плеерами

Клик по иконке расширения → список вкладок с `<video>` / `<audio>`.

- Порядок **как во вкладках браузера** (слева направо), не меняется
- **💤** — вкладка открыта, но не загружена (спящая / discarded); mute работает сразу, play/pause загрузит вкладку
- Кнопки: **▶ Play**, **⏸ Pause**, **🔊/🔇 Mute**
- Управление **без переключения** на вкладку

### 2. Vivaldi mod — ПКМ по вкладке

См. [`vivaldi-mod/README.md`](vivaldi-mod/README.md) — пункт **Play / Pause** в нативном меню вкладки.

## Расширение

| Способ | Описание |
|--------|----------|
| **Popup** | Список вкладок с медиа, play / pause / mute |
| ПКМ по иконке расширения | Play / Pause последней взаимодействовавшей (подсвеченной) вкладки |

Установка: `vivaldi://extensions` → Загрузить расширение → папка `Pause button`
